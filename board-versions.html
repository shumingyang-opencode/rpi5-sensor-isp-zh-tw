為什麼要懂子版本：Raspberry Pi 5 有不同 RAM 版本與多款官方相機配件，功能與適用開發差異明顯。選對版本才能避開「買錯板卡」的坑。

子版本比較

版本SoCRAM關鍵 I/O適合開發
Raspberry Pi 5（2GB）BCM2712 4×A762GB同 RPi5 全 I/O輕量嵌入式、無頭伺服、教學入門
Raspberry Pi 5（4GB）BCM2712 4×A764GB雙 4-lane CSI、雙 4K 顯示、PCIe 2.0、40-pin一般用途、影像處理
Raspberry Pi 5（8GB）BCM2712 4×A768GB同上AI 推論、多任務、影像調校開發
Raspberry Pi 5（16GB）BCM2712 4×A7616GB同上大模型、多執行緒、密集運算

配件與外設

配件說明 / 用途
Camera Module 1（OV5647）本站主例；5MP 官方相機，文件最齊
Camera Module 3（IMX708）12MP、AF 對焦、HDR
HQ Camera（IMX477）高畫質、可換鏡頭
Global Shutter Camera（OV9281）1MP global shutter，機器視覺
官方 7” 觸控螢幕本機 UI 開發
NVMe HAT高速儲存，AI 資料集
Raspberry Pi Pico（MCU）與 RPi5 搭配的即時控制伴侶

選擇建議

  • 影像調校開發首選 8GB：記憶體足夠跑分析工具與多執行緒。
  • 僅做 sensor bring-up 驗證，4GB 已足夠。
  • 相機配件以「和你的感測器/鏡頭」相容為前提再選。
  • 若需 GMSL 多感測器 → 本平台不支援，請看 Jetson 站。
