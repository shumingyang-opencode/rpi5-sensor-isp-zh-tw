4.2 控制資料流（完整）

你設 ExposureTime=20000→libcamera 轉換成感測器曝光→ov5647.c 寫 0x3500…→ISP 統計→IPA 下幀調整

你操作高階控制；libcamera 做「控制→register」轉換。理解這層，tuning 才看得懂。

4.3 unicam：CSI-2 接收器

  • 收集 MIPI 資料流，對應 V4L2 media 節點。
  • 處理：lane 對齊、EAV/SAV、frame 同步。
確認 media 節點
ls /dev/video* /dev/media*
media-ctl -p -d /dev/media0 | head -30

4.4 DT overlay：每個欄位對驅動的意義

ov5647 overlay（概念）
compatible = "ovti,ov5647";     # 匹配 of_device_id
reg = <0x36>;                    # probe 用的 I2C 位址
clocks = <&cam0_clk>;              # XCLK 來源
reset-gpios = <...>;             # RESET（CAM_GPIO）
pwdn-gpios = <...>;              # PWDN
port { csi-lane = <2>; }          # MIPI 2-lane
欄位驅動用途
compatible匹配驅動 → probe
regi2c_new_client_device 位址
clocks供 XCLK
reset-gpiosprobe 時先 reset
確認生效
sudo dtoverlay -a | grep ov56
dmesg | grep -i -E "ov5647|unicam"
