libcamera 架構

libcamera 是 Linux 的開源相機框架，核心元件：

元件角色
PipelineHandler把「感測器+ISP」串成一個 Camera
Camera對應用程式暴露的相機實體
Controls曝光、增益、白平衡等標準化控制介面
IPA（ISP 調適）執行 AE/AWB 等演算法，產出 ISP 參數
調適重點：你設定的是「高階控制」（如 exposure 時間），IPA/ISP 負責轉成 register 與 ISP 參數——理解這層「抽象」是 libcamera tuning 的關鍵。

unicam 與感測器驅動

  • unicam：RPi 的 CSI-2 接收器驅動，負責收集 MIPI 資料。
  • 感測器驅動：如 ov5647.c，實現 libcamera 的 sensor 介面（提供曝光/增益等控制）。

DT overlay：告訴系統「有這顆感測器」

/boot/firmware/config.txt
dtoverlay=ov5647            # 官方 Camera Module v1
dtoverlay=ov9281            # global shutter 板
# 自訂板：dtoverlay=my-sensor 需自備 overlay 檔
客製感測器：要接自訂 OV 板，需要自寫 device tree overlay（宣告 CSI 通道、I2C 位址、reset/clock GPIO）——這是單元 16 的主題。

  • DT overlay 如何啟用感測器。
  • 為什麼「控制抽象」對 tuning 重要。
