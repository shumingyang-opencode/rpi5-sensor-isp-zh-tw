unicam 與感測器驅動

ov5647.c（感測器）→unicam（CSI-2 接收）→pisp ISP→/dev/video0
  • unicam：RPi 的 CSI-2 前端驅動，收集 MIPI 資料流。
  • ov5647.c：實作 libcamera 的 sensor 介面（曝光/增益/白平衡 controls）。

DT overlay：感測器怎麼「被發現」

啟用 OV5647 的 overlay（dtoverlay=ov5647）會把下列資訊掛進 device tree：

ov5647 overlay 宣告（概念）
compatible = "ovti,ov5647";
reg = <0x36>;            # I2C 位址
clocks = <&cam0_clk>;      # XCLK
reset-gpios = <...>;     # RESET
port { ... mipi 2-lane ... };
確認 overlay 生效
sudo dtoverlay -a | grep ov56
# 或重啟後：
dmesg | grep -i -E "ov5647|unicam"

控制模型：Control → IPA → register/ISP

你設 ExposureTime=20000→libcamera→驅動寫 0x3500…→ISP 統計回饋
調適重點：你操作的是高階控制，不是裸 register。理解這層抽象，tuning 才看得懂。
