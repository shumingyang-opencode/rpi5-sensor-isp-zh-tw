2.1 光電轉換的物理模型

光子→photodiode→累積電荷 Q = η·P·Texp→電荷→電壓（SF 源極隨耦器）→ADC→RAW
  • η（量子效率）：光子→電子轉換率，依波長。
  • P：入射光功率。
  • Texp：曝光時間。
  • 滿阱（full well）：單像素最大電荷 → 決定動態範圍。
關鍵數學：shot noise σ = √N（N=訊號電子數）。訊號增 4 倍，σ 只增 2 倍 → SNR 隨訊號增。這解釋「加曝光優於加增益」：增益把訊號與雜訊等量放大，SNR 不變；曝光增加的是「真正的訊號」。

2.2 Bayer CFA 的物理意義

RGrRGr
GbBGbB
RGrRGr
GbBGbB
  • 單像素只有單色：2×2 = 1R+2G+1B。
  • Gr/Gb 差異：Gr（列向 R）與 Gb（行向 B）因製造/crosstalk 有細微差 → ISP 需 Gr/Gb 平衡校正。
  • demosaic：用鄰近像素插值重建全彩（單元 7）。
Bayer order 後果：OV5647=RGGB。若平台以錯誤 order 解讀 → 色彩全錯。單元 8 教你驗證。

2.3 快門時序：Rolling 的流水線

Rolling：逐列「曝光→讀出」，曝光與讀出流水線重疊。row 之間有時間差 → 快速移動物體扭曲。

型態時序OV5647問題
Rolling逐列曝光+讀出✅扭曲、banding
Global全像素同時曝光—電路複雜

banding：曝光時間非電源頻率整數倍 → 亮暗條紋（單元 10 深入）。
