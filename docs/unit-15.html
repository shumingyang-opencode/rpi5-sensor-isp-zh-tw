為什麼要比較

sensor 影像調適的「能力」不只來自感測器，更多來自平台 ISP + 工具鏈。本單元從 RPi5 的角度，對照另外三個平台。

四大平台調校能力總表

項目RPi5Orange PiOrin NanoThor T5000
ISP 形態SoC 硬體 ISP多靠感測器/無完整 ISPNVIDIA ISP（libnvivp）Blackwell + Holoscan
AE/AWBlibcamera 演算法 ✅感測器內建或無 ⚠️NVIDIA 自動 ✅✅NVIDIA 自動 ✅✅
LSC✅ tuning json通常無 ⚠️✅ NVIDIA✅ NVIDIA
NR/Sharpen✅ 可調⚠️ 有限✅✅ 豐富✅✅ 豐富
HDR✅ 多幀⚠️ 依 SoC✅✅✅
調校工具鏈開源、看得見v4l2-ctl（陽春）NVIDIA 工具（部分封閉）Holoscan（新）
tuning 檔libcamera .json—NVIDIA 私有格式NVIDIA 私有格式
可視性/學習性最適合學習陽春但開放強大但不透明新且高階
RPi5 的定位：調校功能不是最強，但「開源 + 文件齊 + 每一層都看得見」讓它是最好的學習平台——學會這裡的觀念，NVIDIA 平台的調校只是換工具。

選型建議

  • 學習/教學 → RPi5。
  • 簡單專案 → Orange Pi（能跑就好）。
  • 工業/高品質 → Orin Nano（GMSL、豐富 ISP）。
  • 次世代機器人 → Thor T5000（Holoscan Sensor Bridge）。
看完這單元你應該能說出：
  • 四平台 ISP 形態與調校能力差異。
  • RPi5 在學習性上的優勢與理由。
  • 各平台調校工具鏈與 tuning 檔差異。
  • 依需求選擇平台的判斷依據。
