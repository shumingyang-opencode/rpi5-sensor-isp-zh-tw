15.1 比較框架

調校能力 = 平台 ISP 可調參數 × 工具鏈完整度 × 可視性。三者相乘才是「你能實際做到什麼」。

RPi5 定位：調校功能不是最強，但「開源 + 文件齊 + 每層看得見」是最好的學習平台——學會這裡的原理，換到 NVIDIA 平台只是換工具。

15.3 選型建議

  • 學習/教學 → RPi5。
  • 簡單專案 → Orange Pi。
  • 工業/高品質 → Orin Nano（GMSL 多感測器）。
  • 次世代機器人 → Thor T5000（HSB 乙太網路感測器）。

15.5 感測器 register 層的共通性

無論平台，OV 感測器的 register 是相同的（0x300A ID、0x3500 曝光、0x350A 增益）——平台差異只在「誰幫你寫」。這正是「先懂 register、再懂平台」的價值。

四平台讀同一個 register
# 都是 OV5640/OV9281 的 ID register 0x300A
RPi5:      i2ctransfer -y 22 w2@0x36 0x30 0x0a r1
Orange Pi: i2ctransfer -y 3  w2@0x3c 0x30 0x0a r1
Orin/Thor: i2ctransfer -y 0  w2@0x36 0x30 0x0a r1
# 差別只在匯流排編號與位址，register 相同
看完這單元你應該能說出：
  • 四平台 ISP 與調校能力。
  • RPi5 學習性優勢。
  • 工具鏈與 tuning 檔差異。
  • 依需求選平台。
