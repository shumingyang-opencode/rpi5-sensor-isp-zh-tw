7.1 ISP 管線全圖

Black Level→Lens Shading→Demosaic→降噪→CCM→Gamma→輸出

7.2 六區塊逐一拆解

區塊演算法/作用調校點設錯症狀
Black Level扣暗電流基準（sensor 黑位 offset）黑位 offset（R/Gr/Gb/B 各自）暗部偏灰/偏黑
Lens Shading網格增益補償鏡頭暗角LSC 網格四周暗/偏色
DemosaicBayer→全彩（插值 + 假色抑制）假色抑制強度鋸齒/彩色摩爾紋
降噪空間/時間降噪（亮度+彩色）NR strength細節糊
CCM3×3 色彩校正（依色溫分段）CCM 矩陣色彩偏差/過飽和
Gamma亮度對比曲線gamma/對比階調異常

7.3 ISP 統計 → AE/AWB 回饋

RAW→ISP→統計：亮度直方圖、色彩平均、AE 值→IPA（AE/AWB）→下一幀控制
看控制與統計
rpicam-still --info -o /dev/null
# 輸出含：ExposureTime, AnalogueGain, AWB gains, 統計摘要
調校核心：先確認黑位 → LSC → CCM → gamma 依序，不要跳著調。每個區塊都對應 tuning 檔的一個 algorithm 區塊（單元 14）。

7.4 測量黑位（實作）

遮鏡頭拍 RAW 統計
rpicam-still --raw --shutter 20000 --gain 1 -o black.dng
python3 - <<'EOF'
import rawpy, numpy as np
raw = rawpy.imread('black.dng').raw_image
print('R mean:', raw[0::2,0::2].mean())
print('Gr mean:', raw[0::2,1::2].mean())
print('Gb mean:', raw[1::2,0::2].mean())
print('B mean:', raw[1::2,1::2].mean())
EOF

四個通道均值應接近（皆為黑位）；若差異大 → 黑位需分通道校正。

看完這單元你應該能說出：
  • ISP 六區塊演算法與調校點。
  • 每區塊「設錯的症狀」。
  • ISP 統計回饋給 AE/AWB 的機制。
  • 用 RAW 測量黑位。
