7.1 管線全圖

Black Level→Lens Shading→Demosaic→降噪→CCM→Gamma→輸出

7.2 六區塊拆解

區塊演算法調校設錯症狀
Black Level扣黑位 offsetoffset R/Gr/Gb/B暗部偏灰/黑
Lens Shading網格增益LSC 網格四周暗/偏色
DemosaicBayer→全彩+假色抑制假色抑制鋸齒/摩爾紋
降噪空間/時間 NRNR strength細節糊
CCM3×3 色彩校正CCM色偏/過飽和
Gamma對比曲線gamma/對比階調異常

7.3 統計回饋機制

RAW→ISP→統計（直方圖/色彩/AE）→IPA→下幀控制
看控制與統計
rpicam-still --info -o /dev/null
# 含 ExposureTime, AnalogueGain, AWB gains, 統計
調校核心：依序黑位→LSC→CCM→gamma，別跳。每區塊對應 tuning 檔一個 algorithm（單元 14）。

7.4 黑位量測實作

遮鏡頭拍 RAW 統計
rpicam-still --raw --shutter 20000 --gain 1 -o black.dng
python3 - <<'EOF'
import rawpy, numpy as np
raw = rawpy.imread('black.dng').raw_image
print('R :', raw[0::2,0::2].mean())
print('Gr:', raw[0::2,1::2].mean())
print('Gb:', raw[1::2,0::2].mean())
print('B :', raw[1::2,1::2].mean())
EOF

四通道均值應接近（黑位）；差異大 → 分通道校正黑位。

看完這單元你應該能說出：
  • ISP 六區塊與調校。
  • 設錯症狀。
  • 統計回饋機制。
  • 黑位量測。
