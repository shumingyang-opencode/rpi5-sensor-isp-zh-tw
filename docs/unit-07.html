RPi5 硬體 ISP 與統計回饋

  • RPi5 ISP 是 SoC 硬體單元，由 libcamera IPA 驅動。
  • ISP 產出統計資料（亮度直方圖、色彩平均、AE 曝光值）回饋給 AE/AWB 演算法。
  • 這些統計就是調校的「輸入資料」——沒有統計，AE/AWB 就是瞎猜。
看 AE 統計（libcamera 暴露）
rpicam-still --info --output /dev/null    # 印出控制與統計摘要
調校核心：先確認「黑位正確 → LSC 補償 → CCM 對色 → gamma 對比」依序來，不要跳著調。
看完這單元你應該能說出：
  • ISP 六區塊的作用與調校對應。
  • 每區塊「設錯的症狀」。
  • ISP 統計如何回饋給 AE/AWB。
  • 調校的依序原則。
