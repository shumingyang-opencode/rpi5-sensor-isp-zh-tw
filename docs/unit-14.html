14.1 清晰度與對比

  • Sharpen：強化邊緣；過度 → 光暈 + 放大雜訊。
  • Contrast/Gamma：對比曲線。
  • NR 與 Sharpen 要成對調適。

14.2 動態範圍與 HDR

  • RPi5 支援 HDR 相機模式（多幀合成）。
  • 啟用：dtoverlay=...hdr + libcamera HDR 模式。
  • tone mapping：高動態壓回輸出範圍。

14.3 libcamera tuning 檔完整解析

關鍵 algorithm 區塊
{ "version": 1,
  "algorithms": [
    { "Awb":        { "mode": "auto" } },
    { "BlackLevel": { "r": 4096, "gr": 4096, "gb": 4096, "b": 4096 } },
    { "ColourMatrix": { "ccm": [ ... ] } },
    { "Denoise":   { "strength": 0.3 } },
    { "LensShading": { "meshes": [ ... ] } },
    { "Contrast":  { "strength": 1.0 } }
  ] }
區塊作用對應單元
Awb白平衡演算法11
BlackLevel黑位 offset7
ColourMatrixCCM11
Denoise降噪13
LensShadingLSC 網格12
Contrast對比/gamma14

改檔後重啟程式生效。備份原檔。

14.4 完整調校工作流

  1. 準備：灰卡、色卡、均勻光源、固定曝光。
  2. 校正順序：黑位→LSC→AWB/CCM→曝光基準。
  3. 動態：AE/AWB convergence 與範圍。
  4. 美化：NR↔Sharpen、色彩喜好。
  5. 回歸：室內/日光/逆光。
紀律：一次只改一個參數、記錄前後、統一場景比較。

  • 五步工作流。
