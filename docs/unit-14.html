清晰度與對比

  • Sharpen：強化邊緣；過度 → 光暈（halo）+ 放大雜訊。
  • Contrast / Gamma：對比曲線。
  • 調校陷阱：NR 與 Sharpen 要成對調適。

動態範圍與 HDR

  • RPi5 支援 HDR 相機模式（多幀合成擴展動態範圍）。
  • 啟用：dtoverlay=...hdr 系列設定 + libcamera HDR 模式。
  • tone mapping：把高動態壓回輸出範圍，決定亮暗部細節去留。

tuning 檔完整解析（libcamera .json）

結構（關鍵區塊）
{ "version": 1,
  "algorithms": [
    { "Awb": { "mode": "auto" } },
    { "BlackLevel": { "r": 4096, "gr": 4096, "gb": 4096, "b": 4096 } },
    { "ColourMatrix": { "ccm": [ ... ] } },
    { "Denoise": { "strength": 0.3 } },
    { "LensShading": { "meshes": [ ... ] } },
    { "Contrast": { "strength": 1.0 } }
  ] }

每個 algorithm 區塊對應 IPA 的一個演算法，是 RPi 調校的「單一來源」。改檔後重啟程式即生效。

完整調校工作流（照做）

  1. 準備：灰卡、色卡、積分球/均勻光源、固定曝光。
  2. 校正順序：黑位 → LSC → AWB/CCM → 曝光基準。
  3. 動態：AE/AWB convergence 與範圍。
  4. 美化：NR ↔ Sharpen 平衡、色彩喜好。
  5. 回歸：不同場景（室內/日光/逆光）跑一輪，確認沒改壞。
核心紀律：一次只改一個參數、記錄前後、統一場景比較。調校最忌「一次改一堆」。
