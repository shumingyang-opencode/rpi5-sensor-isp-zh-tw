清晰度（Sharpness / Contrast）

  • Sharpen：增強邊緣對比；過度會產生光暈（halo）。
  • Contrast：整體對比曲線；與 gamma 一起看。
  • 調校陷阱：銳化會放大雜訊——通常 NR 與 Sharpen 要成對調適。

動態範圍與 HDR

場景亮暗差異大時（逆光、窗邊），單幀 8-bit 不夠用：

  • 多幀 HDR：RPi5 支援 HDR 相機模式，合成多幀擴展動態範圍。
  • tone mapping：把高動態範圍壓回輸出範圍，決定暗部/亮部細節去留。
RPi5 亮點：內建 HDR 模式，可開啟 dtoverlay=...hdr 系列設定做多幀合成調校。

tuning 檔格式（libcamera .json）

libcamera tuning 結構（示意）
{ "version": 1,
  "algorithms": [
    { "Awb":     { "mode": ... } },
    { "ColourMatrix": { "ccm": [...] } },
    { "Denoise": { "strength": ... } },
    { "LensShading": { "meshes": [...] } }
  ] }

每一區塊對應 IPA 的一個演算法，是 RPi 調校的「單一來源」。

完整調校工作流

  1. 拍測試圖：灰卡 / 色卡 / 積分球，固定光源與曝光。
  2. 校正：黑位、LSC、CCM、AWB 基準。
  3. 動態調校：AE/AWB 的 convergence 與範圍。
  4. 主觀微調：NR / Sharpen / 色彩喜好。
  5. 回歸驗證：不同場景跑一輪，確認沒改壞其他情況。
核心紀律：每次只改一個參數、記錄前後、用統一場景比較——調校最忌「一次改一堆」。
