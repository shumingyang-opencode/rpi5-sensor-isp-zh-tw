步驟 0：啟用相機並重啟

啟用
sudo raspi-config        # Interface Options → Camera → Enable
sudo reboot

步驟 1：確認相機被偵測

列出相機
rpicam-hello --list-cameras
# 預期看到 ov5647，含支援的 mode（如 2592x1944 10-bit）
若沒列出：排線？overlay？dmesg | grep -i -E "ov5647|unicam|error" 找線索（單元 6）。

步驟 2：即時預覽（確認鏈路）

rpicam-hello
rpicam-hello -t 10s     # 預覽 10 秒；看到畫面=感測器→ISP→輸出通

步驟 3：拍照與錄影

still / vid / raw
rpicam-still -o shot.jpg                    # JPEG
rpicam-still --raw -o shot.dng              # 同時輸出 RAW（.dng）
rpicam-vid -t 5s -o video.h264             # H.264 錄 5 秒
RAW 的重要性：--raw 會同時存 .dng（Bayer RAW）。影像品質分析（黑位、雜訊、Bayer order）一定要回到 RAW。

步驟 4：Python（picamera2）

拍照 + 設定曝光
from picamera2 import Picamera2

picam2 = Picamera2()
cfg = picam2.create_still_configuration()
picam2.configure(cfg)
picam2.set_controls({"ExposureTime": 20000, "AnalogueGain": 1.5})
picam2.start()
picam2.capture_file("shot.jpg")
picam2.stop()

常見失敗快速對照

症狀方向
--list-cameras 空overlay / 排線 / dmesg
預覽全黑曝光/增益為 0？鏡頭蓋？自動曝光未啟動
畫面有雜訊條banding → 曝光與電源頻率（單元 10）
顏色全錯Bayer order / 白平衡（單元 8、11）
看完這單元你應該能說出：
  • 啟用相機並用 --list-cameras 確認偵測。
  • rpicam-hello/still/vid 的完整用法。
  • 用 --raw 取得 DNG 供調校。
  • picamera2 控制曝光拍照。
  • 四種常見失敗的快速方向。
