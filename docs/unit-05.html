rpicam-apps 拍照與串流

啟用相機

RPi5 設定
sudo raspi-config       # Interface Options → Camera → Enable
sudo reboot

rpicam-apps 一組指令

預覽 / 拍照 / 錄影
rpicam-hello                 # 即時預覽（確認相機有畫面）
rpicam-still -o photo.jpg    # 拍照
rpicam-vid -o video.h264     # 錄影
第一步驗證：跑 rpicam-hello 能看到畫面，代表 sensor→ISP→輸出整條鏈路是通的——後續 tuning 才有意義。

RAW 輸出（為調校做準備）

同時存 RAW + 處理後影像
rpicam-still --raw -o shot.jpg   # 額外產生 .dng（RAW 檔）

Python：picamera2

picamera2 最小範例
from picamera2 import Picamera2
picam2 = Picamera2()
still = picam2.still_configuration()
picam2.configure(still)
picam2.start()
picam2.capture_file("shot.jpg")
看完這單元你應該能說出：
  • 用 raspi-config 啟用相機。
  • rpicam-hello/still/vid 各自用途。
  • 如何取得 RAW（.dng）供調校。
  • picamera2 最小範例結構。
