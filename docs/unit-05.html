5.1 啟用相機

raspi-config
$ sudo raspi-config
  Interface Options → Camera → Enable
$ sudo reboot

5.2 確認偵測（含輸出解讀）

list-cameras
$ rpicam-hello --list-cameras
0 : ov5647 [2592x1944 10-bit RGGB]
    Modes: 'SGBRG10_CSI2P' : 640x480 1296x972 1296x730 2592x1944
           'YUV420_8_CSI2P' : 640x480 1296x972 1296x730 2592x1944

libcamera 顯示 SGBRG10（CSI 層排列）；OV5647 實際 RGGB——轉換在單元 8 講。

5.3 預覽 / 拍照 / 錄影（關鍵旗標）

主指令
rpicam-hello -t 10000              # 預覽 10s
rpicam-still -o shot.jpg
rpicam-still --raw -o shot.dng     # 同時輸出 DNG（調校關鍵）
rpicam-vid -t 5000 -o video.h264
旗標作用
-t持續 ms
--raw額外輸出 DNG
--shutter/--gain/--awb固定參數（調校用）
--info印控制與統計
RAW 的意義：DNG 是 Bayer RAW。品質分析（黑位、雜訊、色彩）回 RAW。習慣：rpicam-still --raw -o t.dng。

5.4 調校用固定參數拍照

固定曝光/增益/AWB
rpicam-still --raw -o fixed.dng     --shutter 20000 --gain 1.0 --awb off --awbgains 1.0,1.0

5.5 picamera2 完整程式

控制曝光/AWB 拍照
from picamera2 import Picamera2
picam2 = Picamera2()
cfg = picam2.create_still_configuration()
picam2.configure(cfg)
picam2.set_controls({
    "AeEnable": False, "ExposureTime": 20000, "AnalogueGain": 1.5,
    "AwbEnable": False, "ColourTemperature": 4500,
})
picam2.start()
picam2.capture_file("shot.jpg")
picam2.stop()
