5.1 啟用相機

raspi-config
$ sudo raspi-config
  Interface Options → Camera → Enable
$ sudo reboot

5.2 確認偵測（含預期輸出）

rpicam-hello --list-cameras
$ rpicam-hello --list-cameras
Available cameras
-----------------
0 : ov5647 [2592x1944 10-bit RGGB]
    Modes: 'SGBRG10_CSI2P' : 640x480  1296x972  1296x730  2592x1944
           'YUV420_8_CSI2P' : 640x480  1296x972  1296x730  2592x1944

注意：libcamera 顯示 SGBRG10（Bayer order 的 CSI 呈現），但 OV5647 是 RGGB——order 的對應關係在單元 8 講解。

5.3 預覽 / 拍照 / 錄影（含關鍵旗標）

rpicam-apps 主指令
# 預覽 10 秒（確認鏈路）
rpicam-hello -t 10000

# 拍照：JPEG + RAW(DNG)
rpicam-still -o shot.jpg
rpicam-still --raw -o shot.dng      # 同時輸出 DNG（調校關鍵）

# 錄影
rpicam-vid -t 5000 -o video.h264
旗標作用
-t持續時間 ms
--raw額外輸出 RAW（DNG）
--shutter/--gain/--awb固定曝光/增益/白平衡（調校用）
--info印出控制與統計
RAW 的意義：DNG 是 Bayer RAW 封裝。所有品質分析（黑位、雜訊、色彩）都要回 RAW。拍 RAW 習慣：rpicam-still --raw -o t.dng。

5.4 調校用的固定參數拍照

固定曝光/增益/AWB 拍 RAW（後續單元用）
rpicam-still --raw -o fixed.dng     --shutter 20000 --gain 1.0 --awb off     --awbgains 1.0,1.0

5.5 picamera2 完整程式

控制曝光拍照
from picamera2 import Picamera2

picam2 = Picamera2()
cfg = picam2.create_still_configuration()
picam2.configure(cfg)

picam2.set_controls({
    "AeEnable": False,          # 關自動
    "ExposureTime": 20000,      # 微秒
    "AnalogueGain": 1.5,
    "AwbEnable": False,
    "ColourTemperature": 4500,
})
picam2.start()
picam2.capture_file("shot.jpg")
picam2.stop()

5.6 常見失敗快速對照

症狀方向詳見
list-cameras 空overlay / 排線 / dmesg單元 1/6
預覽全黑曝光 0 / AE 未跑 / 鏡頭蓋單元 10
雜訊條（banding）曝光與 50/60Hz單元 10
色彩全錯Bayer order / AWB單元 8/11

  • rpicam-apps 主指令與關鍵旗標。
  • 用 --raw 取 DNG 供調校。
  • picamera2 控制曝光/AWB 拍照。
