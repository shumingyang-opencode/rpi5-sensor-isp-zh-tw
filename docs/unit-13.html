雜訊從哪來

雜訊來源特性
光子 shot noise光子隨機性低光時最明顯
read noise讀出電路與曝光無關的底噪
暗電流（dark current）高溫/長曝光越熱越嚴重
hot pixel缺陷像素固定亮點

降噪的策略與取捨

鐵律：降噪的敵人永遠是「細節」。NR 調太強，畫面變「塑膠感」——調校就是找雜訊 vs 細節的平衡點。
  • 亮度降噪：影響畫面整體，最容易過度。
  • 彩色降噪：抑制色斑（chroma noise），可稍強。
  • 時間降噪（temporal NR）：多幀平均，換幀率。

RPi libcamera 的降噪調校

tuning 檔中的降噪區塊（示意）
{ "ColourDenoise":  { "strength": 0.5, ... },
  "Denoise":        { "strength": 0.3, ... } }

rpicam-apps 提供即時切換強度以 A/B 比較的介面。

感測器端：缺陷像素校正（DPC）

OV 感測器多有內建 DPC（defect pixel correction），可標定並替換缺陷像素。感測器端先修掉 hot pixel，ISP 端再做 NR，效果最佳。
