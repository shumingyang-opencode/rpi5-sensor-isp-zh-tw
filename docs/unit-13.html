雜訊來源

雜訊來源特性
shot noise光子隨機性低光最明顯（σ ∝ √光）
read noise讀出電路底噪，與曝光無關
dark current高溫/長曝光越熱越嚴重
hot pixel缺陷像素固定亮點

libcamera 降噪調校

tuning 檔的 Denoise 區塊（示意）
{ "Denoise":  { "strength": 0.3, "sharpen": 0.5 } }
  • 亮度降噪：影響整體細節。
  • 彩色降噪：抑制色斑，可稍強。
  • 取捨：NR 太強 → 「塑膠感」。降噪與細節永遠是平衡。

感測器端 DPC

OV5647 內建 DPC（缺陷像素校正），可先修掉 hot pixel。流程：感測器端先 DPC → 平台 ISP 再 NR，效果最佳。

調校紀律：先確認增益沒拉太高（源頭），再讓 NR 收尾——否則 NR 只是「擦更髒的畫面」。
