I2C 與 SCCB

感測器幾乎都用 I2C（或 OmniVision 早年慣用的 SCCB——與 I2C 相容的簡化協定）來設定 register。RPi 上的感測器通常掛在 i2c-10/i2c-22 等匯流排，位址如 OV5647 = 0x36（7-bit）。

讀取感測器（i2c-tools）
sudo i2cdetect -y 10          # 掃描匯流排找感測器位址
sudo i2cget -y 10 0x36 0x300a  # 讀 OV5647 ID 高位元組

OV register 慣例

  • 16-bit register 位址：OV 感測器用 16-bit 位址（如 0x300A），與常見 8-bit 位址感測器不同。
  • 感測器 ID：多在 0x300A/0x300B，例如 OV5647 讀回 0x56/0x47。
  • Page switching：部分 OV 感測器把 register 分頁（透過 0xFD/0xFE 切換），修改前要確認當前 page。
Register功能範例值
0x300A / 0x300B感測器 ID0x56 / 0x47（OV5647）
0x3034–0x3037PLL 分頻設定依 input clock
0x3500–0x3503AEC/曝光時間曝光行數
除錯第一招：感測器接上去「沒畫面」時，先 i2cdetect 確認感測器是否回應、再讀 ID register——很多問題其實是「根本沒通訊上」。

register 讀寫的實務

直接寫 register（僅除錯用）
sudo i2cset -y 10 0x36 0x3034 0x1e    # 寫 PLL 相關 register
sudo i2cget -y 10 0x36 0x3034          # 回讀驗證

正式流程請透過感測器驅動（libcamera 控制）設定，避免手動寫壞。
