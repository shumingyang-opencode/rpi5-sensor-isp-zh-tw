8.1 V4L2 Bayer format 與 fourcc

fourcc排列OV5647
SRGGB10R 起點 10-bit✅ RAW
SGBRG10Gb 起點CSI 呈現
YUYV/NV12ISP 輸出✅
order 迷思：libcamera 顯示 SGBRG10_CSI2P 是傳輸層排列；實際 RGGB。driver 處理轉換；你手動解析 RAW 時以 RGGB 為準。

8.2 驗證 Bayer order

用 dng 檢查
python3 - <<'EOF'
import rawpy, numpy as np
raw = rawpy.imread('t.dng').raw_image
h, w = raw.shape
roi = raw[h//4:3*h//4, w//4:3*w//4]
cells = [roi[0::2,0::2].mean(), roi[0::2,1::2].mean(),
         roi[1::2,0::2].mean(), roi[1::2,1::2].mean()]
print('R=%.1f Gr=%.1f Gb=%.1f B=%.1f' % tuple(cells))
EOF
症狀：order 錯 → 色彩全亂。拍純色卡判別。

8.4 ROI / binning

  • Full：2592×1944。
  • Binning：2×2 合併。
  • 調校固定「同 size+format」，避免 binning 漂移。
