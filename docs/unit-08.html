為什麼調校要先懂 RAW

所有影像品質分析（雜訊、色彩、曝光）都要回到 RAW 資料——因為 ISP 處理過就「回不去」了。

Bayer format 與 order

RAW 有四種 Bayer 起點（RGGB / BGGR / GRBG / GBRG）。設定錯 order，顏色會「全錯」。

rpicam-still 指定 RAW 格式
rpicam-still --raw -o shot.dng            # 以 .dng 存 RAW
rpicam-still --raw --list-cameras         # 看支援的格式/解析度

bit depth 與動態範圍

位元深灰階數意義
8-bit256最終輸出常見
10-bit1024常見感測器 RAW
12-bit4096高動態範圍調校需要
陷阱：RAW 位元深 > 輸出位元深時，tone mapping / gamma 決定暗部細節的去留——這是調校的重要戰場。

ROI 與解析度

  • Full resolution：感測器全像素讀出。
  • Binning / Cropping：合併像素或裁切（影響感光與視角）。
  • libcamera 用 StreamConfiguration 設定 size / pixel format。
實務：調校時固定「同一個 size + 同一個 format」，避免 binning 造成的參數漂移。
看完這單元你應該能說出：
  • 為什麼調校必須回到 RAW。
  • 四種 Bayer order 與設定錯誤的後果。
  • bit depth 對動態範圍的影響。
  • ROI/binning 對調校的影響。
