為什麼調校前先懂 RAW

ISP 處理過就「回不去」——雜訊、黑位、色彩都要在 RAW 上看才準。

V4L2 Bayer format（RPi）

fourcc說明OV5647
SRGGB1010-bit Bayer（RGGB 起點）✅ 預設 RAW
YUYV/NV12ISP 處理後✅ 輸出

Bayer order 錯的症狀：色彩全亂（綠→紅、紅→藍）。OV5647 是 RGGB（Gr 在第一列第二位）。

bit depth 與動態範圍

位元灰階意義
8256輸出常見
101024OV5647 RAW
124096高動態範圍需要
調校陷阱：RAW 10-bit → 輸出 8-bit，tone mapping / gamma 決定暗部細節去留——這是「看起來有階調 vs 一片黑」的分界。
