10.1 曝光三要素（含位元級）

要素register位元/公式
快門（曝光行數）0x3500–0x3503值 = (0x3501<<12)|(0x3502<<4)|(0x3503>>4)，再 -1（依 datasheet）
類比增益0x350A–0x350Bgain 對應表（見 datasheet gain map）
數位增益ISP 端最後手段
讀目前曝光三 register
for r in 0x3501 0x3502 0x3503; do
  h=${r:2:2}; l=${r:4:2}
  printf "%s: " "$r"; sudo i2ctransfer -y 22 w2@0x36 0x$h 0x$l r1
done
調適順序鐵則：先快門 → 類比增益 → 數位增益。用增益補曝光會犧牲畫質。

10.2 banding 與 50/60Hz（含 register）

曝光時間若不是電源頻率（50Hz=10ms 半週期 / 60Hz≈8.33ms）的整數倍，會出現明暗條紋。

Register功能
0x3A00–0x3A03banding filter（auto）設定
0x3A02/0x3A0350/60Hz 對應曝光行數
除錯：室內燈光下出現 banding → 確認曝光為 50/60Hz 整數倍；libcamera 有 banding 支援。

10.3 libcamera/picamera2 正確控制

AE 控制
picam2.set_controls({
    "AeEnable": False,
    "ExposureTime": 20000,
    "AnalogueGain": 2.0,
    "AeMeteringMode": 1,        # 1=矩陣 2=中心加權 3=點
    "ExposureCompensation": 0.0,  # EV
})

10.4 AE 收斂與除錯

觀察 AE 狀態
rpicam-still --info -o /dev/null | grep -E "Exposure|Gain|Colour"
症狀檢查
AE 到極限仍暗快門上限太低？增益上限太低？補光
收斂慢/閃爍測光區域、EV、convergence 參數
banding曝光非 50/60Hz 整數倍
除錯核心：先看 AE 是否「受限」。受限 → 補光或放寬上限，別硬調增益。
