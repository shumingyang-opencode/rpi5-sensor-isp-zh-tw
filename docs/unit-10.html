曝光三要素與 OV5647

要素OV5647 register影響
快門（曝光行數）0x3500–0x3503進光量；太長模糊/banding
類比增益0x350A–0x350B放大訊號；太高加噪
數位增益ISP 端最後手段，放大雜訊
調適順序鐵則：先快門（曝光量）→ 再類比增益 → 最後數位增益。用增益「補」曝光會犧牲畫質。

OV5647 曝光 register 讀寫（實作）

讀目前曝光
sudo i2ctransfer -y 22 w2@0x36 0x35 0x00 r1   # 0x3500 高位
sudo i2ctransfer -y 22 w2@0x36 0x35 0x01 r1   # 0x3501
sudo i2ctransfer -y 22 w2@0x36 0x35 0x02 r1   # 0x3502

曝光值 = (高<<12 | 中<<4 | 低>>4) 行數。驅動（libcamera）會算好，這裡只是理解。

用 libcamera 控制曝光（正確方式）

picamera2
picam2.set_controls({
    "AeEnable": False,          # 關自動
    "ExposureTime": 20000,      # 微秒
    "AnalogueGain": 2.0,
})

AE 收斂與測光

  • libcamera AE 依 ISP 統計（亮度直方圖）調整曝光；測光模式決定參考區域（中心/矩陣/點）。
  • EV 補償：整體調亮/調暗偏移。
  • 曝光範圍限制：避免快門過長（模糊）或過短（暗）。
測光與 EV（picamera2）
picam2.set_controls({
    "AeMeteringMode": 1,     # 1=矩陣 2=中心加權 3=點測光
    "ExposureCompensation": 1.0,   # +1 EV
})

AE 除錯：畫面過暗/過亮

症狀檢查
AE 已到極限仍暗快門上限太低？增益上限太低？場景太暗（補光）
AE 收斂慢 / 閃爍測光區域、EV 補償、convergence 速度參數
低頻 banding曝光不是電源頻率(50/60Hz)的整數倍
除錯核心：先看 AE 是否「受限」——受限就補光或放寬上限，而不是硬調增益。
