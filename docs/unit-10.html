10.1 曝光三要素（含位元級）

要素register位元/公式
快門（曝光行數）0x3500–0x3503值 = (0x3501<<12)|(0x3502<<4)|(0x3503>>4) − 1（依 datasheet）
類比增益0x350A–0x350B對應 datasheet gain map
數位增益ISP 端最後手段
讀目前曝光三 register
for r in 0x3501 0x3502 0x3503; do
  h=${r:2:2}; l=${r:4:2}
  printf "%s: " "$r"; sudo i2ctransfer -y 22 w2@0x36 0x$h 0x$l r1
done
順序鐵則：先快門→類比增益→數位增益。用增益補曝光犧牲畫質。

10.2 Worked Example：算出曝光值

假設讀回 0x3501=0x01, 0x3502=0xE4, 0x3503=0x10
# 曝光行數（依 0x3503[3:0] 為低位）
exposure = (0x01 << 12) | (0xE4 << 4) | (0x10 >> 4)
         = 4096 + 3648 + 1 = 7745 行
# 再乘 row time 得實際時間

10.3 banding 與 50/60Hz

曝光非電源頻率整數倍 → 明暗條紋。50Hz 半週期 10ms；60Hz ≈8.33ms。

Register功能
0x3A00–0x3A03banding filter 設定
0x3A02/0x3A0350/60Hz 對應曝光行數

10.4 libcamera/picamera2 正確控制

AE 控制
picam2.set_controls({
    "AeEnable": False,
    "ExposureTime": 20000,
    "AnalogueGain": 2.0,
    "AeMeteringMode": 1,        # 1矩陣 2中心 3點
    "ExposureCompensation": 0.0,
})

10.5 AE 收斂除錯

觀察 AE 狀態
rpicam-still --info -o /dev/null | grep -E "Exposure|Gain|Colour"
症狀檢查
AE 到極限仍暗快門/增益上限太低？補光
收斂慢/閃爍測光區域、EV、convergence
banding曝光非 50/60Hz 整數倍
除錯核心：先看 AE 是否受限。受限 → 補光或放寬上限。
