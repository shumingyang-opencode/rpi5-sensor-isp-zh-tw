多相機

RPi5 有 2 組 CSI 連接器，可同時跑兩顆感測器。libcamera 以「多 Camera」呈現，應用可同時操作。

列出所有相機
rpicam-hello --list-cameras     # 顯示每顆感測器的 mode

客製 OV 感測器接入（核心技能）

  1. 自寫 DT overlay：宣告 CSI、I2C 位址、reset/clock GPIO。
  2. 感測器驅動：libcamera 需感測器 driver 支援（或沿用相容驅動）。
  3. 感測器 init：以公開 register 資料設定（曝光/gain 基本控制）。
  4. 基本 tuning：先確認出圖，再做黑位/LSC/色彩。
NDA 提醒：完整 register 表常需 NDA。本站只用公開可查的 register；正式開發請以 OVT 官方文件為準。

完整案例：調校一顆 OV 感測器

接板+overlay→出圖驗證→RAW 檢查→黑位/LSC→AWB/CCM→NR/Sharpen→回歸
  1. rpicam-hello 出圖 → 確認鏈路。
  2. 存 RAW → 分析 Bayer、黑位、缺陷像素。
  3. 灰卡校正黑位與 LSC。
  4. 色卡校正 AWB 與 CCM。
  5. 實景微調 NR/Sharpen。
  6. 不同場景回歸，確認無副作用的調校。

最佳實踐總結

  • 固定測試場景與光源，量化比較。
  • 每次只改一個參數。
  • 先 RAW 後 ISP，先校正後美化。
  • 記錄每次改動與前後圖。
課程完成：你已具備從感測器基礎到影像調校的完整能力，可開始接任何 OV 感測器並把畫面調好。
