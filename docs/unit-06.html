Bring-up 的四件事

檢查項驗證
電源AVDD/DOVDD/DVDD 到位、時序正確
ClockXCLK 有輸出；感測器 PLL 鎖定（讀 0x3037 狀態）
I2Ci2cdetect 找得到位址、讀得到 ID
MIPImedia-ctl / dmesg 確認 CSI-2 有資料

上電時序

電源穩定→XCLK→RESET 釋放→I2C 可通→輸出 MIPI
常見錯誤：RESET 還沒釋放就下 I2C 指令，register 會「看起來能寫但沒生效」。

PLL 與 clock

OV5647 由 XCLK（典型 24 MHz）經內部 PLL 產生感測器主時脈。PLL 設定不當會導致「畫面有但 fps 異常」或「完全黑畫面」。

檢查 PLL 狀態（範例）
sudo i2cget -y 10 0x36 0x3037   # PLL 相關；依 datasheet 解讀

用 media-ctl 看管線

觀察 media graph
sudo media-ctl -p -d /dev/media0    # 列出感測器→unicam→ISP 實體

Bring-up 問題檢查表

症狀可能原因
全黑畫面曝光/增益為 0、感測器未輸出、ISP 未配置
畫面雜訊電源不穩、clock 不乾淨
顏色錯誤Bayer order 設定錯誤（單元 8）
