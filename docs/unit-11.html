單元 11 · 白平衡與色彩（AWB / CCM）

色溫、gains、色彩校正

白平衡（AWB）

人眼會適應光源色溫，感測器不會——所以需要 AWB 把「白」校正回白。做法是對 R/G/B 通道套不同 gains：

場景色溫（如 3000K 黃光）→R/G/B gains→白回白
  • Grey world：假設場景平均是灰，調到 RGB 平均相等。
  • libcamera 的 Awb 演算法依 ISP 統計自動調 gains；也可手動固定色溫。
固定白平衡（picamera2）
picam2.set_controls({"ColourTemperature": 4500, # 手動色溫
                     "AwbEnable": 0})

色彩校正矩陣（CCM）

感測器的色彩響應不完美，需要 3×3 矩陣把 sensor RGB 校正到標準色彩空間。CCM 通常隨色溫分段（低色溫/高色溫各一套）。

CCM 範例（示意）
{ {1.6, -0.3, -0.3},
  {-0.2,  1.4, -0.2},
  {-0.1, -0.3,  1.4} }
調適陷阱：CCM 調過頭會「過飽和」；gains 與 CCM 要一起看，只調其一常顧此失彼。

感測器端 AWB 與 OV register

OV5647 的 AWB 也可由感測器內部處理（相關 register 如 0x5180 起的 AWB 區塊）。實務上 RPi5 多用 libcamera 端 AWB，感測器端保持中性。

看完這單元你應該能說出：
  • AWB 的原理與 gains 的角色。
  • 手動 vs 自動白平衡的設定方式。
  • CCM 的作用與隨色溫分段的觀念。
  • gains 與 CCM 需一起調適。
