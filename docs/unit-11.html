11.1 AWB 原理

場景色溫（3000K）→R/G/B gains→白回白
  • Grey world：假設場景平均灰 → RGB 平均相等。
  • libcamera Awb 演算法依 ISP 統計自動算。

11.2 灰卡校正標準程序

  1. 拍灰卡（固定光源/曝光）。
  2. 關 AWB，手動調 gains 直到灰卡 R=G=B。
  3. 記錄該色溫 gains → 建色溫→gains 表。
picamera2 手動白平衡
picam2.set_controls({
    "AwbEnable": False,
    "ColourTemperature": 4500,
    "RedGain": 1.6, "BlueGain": 1.2,
})

11.3 CCM：色彩校正矩陣

感測器色彩響應不完美，用 3×3 矩陣校正到標準色彩空間；分色溫兩套。

CCM 示意
{ {1.6, -0.3, -0.3},
  {-0.2,  1.4, -0.2},
  {-0.1, -0.3,  1.4} }
陷阱：CCM 過頭 → 過飽和/色階斷裂；gains 與 CCM 一起看。

11.4 用色卡算 CCM（量化）

  1. 拍 X-Rite 色卡（固定光源/曝光）。
  2. 讀色塊 RGB（RAW 經中性 AWB）。
  3. 對目標值算最小化 ΔE 的 3×3。
  4. 寫入 tuning 檔（單元 14）。
  5. 不同色溫重複 → 分段 CCM。
