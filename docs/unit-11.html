AWB 原理：把白校正回白

場景（如 3000K 黃光）→R/G/B gains→白回白

不同色溫下，感測器對 R/B 的靈敏度不同。AWB 就是算出一組 gains 讓中性色中性。

  • Grey world：假設場景平均是灰 → 調到 RGB 平均相等。
  • libcamera Awb 演算法依 ISP 統計自動算 gains。

實作：固定白平衡

picamera2
picam2.set_controls({
    "AwbEnable": False,
    "ColourTemperature": 4500,     # 手動色溫 K
    # 或用 RedGain/BlueGain 直接指定：RedGain=1.6, BlueGain=1.2
})
調適陷阱：固定色溫時，若 gains 與色溫不匹配，白色會偏——用灰卡校正最準（拍灰卡 → 調整直到灰卡中性）。

CCM：色彩校正矩陣

感測器色彩響應不完美，用 3×3 矩陣把 sensor RGB 校正到標準色彩空間；通常分色溫兩套（低/高色溫）。

CCM 示意
{ {1.6, -0.3, -0.3},
  {-0.2,  1.4, -0.2},
  {-0.1, -0.3,  1.4} }
調適要點：CCM 過頭 → 過飽和/色階斷裂；gains 與 CCM 要一起看。先 AWB 中性，再 CCM 定色。

色彩調校實作流程

  1. 拍 X-Rite 色卡（固定光源、固定曝光）。
  2. 關 AWB，手動調 gains 讓色卡白塊中性。
  3. 用色卡目標值 vs 實際值算 CCM（最小化 ΔE）。
  4. 寫入 libcamera tuning 檔（單元 14）。
  5. 不同色溫重複，產生分段 CCM。
